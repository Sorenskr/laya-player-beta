## ✨ 核心功能总览

1. **四大跨端视口模式一键切换**
   - `💻 电脑网页端 (16:9)`、`📱 手机横屏影音 (16:9)`、`📲 手机竖屏社区 (9:16)`、`🔄 竖屏全屏观看 (16:9)`
   - 支持 **独立取景框（绿框）** 自由拖拽与缩放、自动消除源视频边缘白边（`12px` 出血内缩）、顶底暗角柔化蒙层。

2. **Laya 沉浸式直播间（两阶段进房 + 1:1 像素级光效导出）**
   - **两阶段动效**：支持「阶段一：外流推荐页动态音波呼吸头像」与「阶段二：沉浸式直播内页」切换。
   - **高频互动公屏**：自动滚屏弹幕 + 底部独立「`XXX 來了`」高频进场通道 + 原生 SVG 蓝钻/星钻/粉丝团勋章 + **双击任意弹幕原地编辑**。
   - **内置 Gemini AI 看片自动配弹幕**：零配置抽取当前视频关键帧，AI 识别人物动作与剧情自动生成地道台湾繁体直播弹幕。
   - **真实送礼状态机**：16 款热门直播礼物，每次弹出自动切换不同真人头像 + 昵称 + 礼物，支持自定义 **停留时间 / 渐隐消失时间 / 送礼间隔时间**。
   - **右下角飘心与气泡表情**：内置柔和微光晕（`24px` 径向暖光 + 立体投影），基于离屏 Canvas 精灵缓存（`Offscreen Sprite Cache`）实现 60fps 零卡顿。
   - **15 项直播间元素独立显隐开关矩阵**：任意部件一键隐藏/显示，预览与导出实时同步。

3. **Laya App 繁体社区评论区工作台**
   - 内置 200+ 条台港澳马新海外繁体热评与高清亚洲帅哥/美女/萌宠/动漫真实头像库。
   - 支持 **作者回复**、**二级网友跟评**、评论抽屉高度鼠标上下拖拽（`28% ~ 78%`）与字号缩放，每项属性均配独立 🎲 随机筛子按钮。

4. **所见即所得交互与舞台放大镜**
   - **点击画面即定位**：点击左侧预览画面任意 UI 部件，右侧工作台自动展开对应面板、滚动置顶并高亮闪烁。
   - **舞台放大镜 (`50% ~ 350%`) + 抓手平移 (`M` 键)**：支持滚轮无级缩放与画布自由拖拽平移。

5. **WebCodecs 16Mbps 超清 H.264 + AAC 手机直发导出（帧级时长锁定）**
   - 采用 `avc1.640028` (High Profile) `16 Mbps` 30fps 硬件编码 + `faststart` 封装，iOS / Android 手机相册与社交平台直发即播。
   - **选多少秒就导多少秒**：支持 `0.1 秒` 小数精度裁剪与导出（如设定 `13.6s` 即严格输出 `408` 帧 `13.60s`），绝不提前截断。
   - **虚拟超长总时长进度条**：支持将短片段映射到 `02:00:00` 等超长虚拟总时长任意起点一秒一秒真实走表，播完即停不循环。
