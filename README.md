**Laya 播放器 · 全真机录屏与截图工作台** 是一款纯前端零依赖安装、支持离线直开与云端协作的跨端视频包装、真机 UI 模拟、沉浸式直播间合成与超清 MP4 导出引擎。只需拖入一段原始视频或图片，即可一键套用 **电脑网页端 / 手机横屏影音 / 手机竖屏社区 / 竖屏全屏观看** 四大真机壳层，自动匹配 AI 视觉弹幕与海外华人社区互动评论，并通过硬件加速直接输出无马赛克、音画同步、手机相册直发的 **1080P H.264 + AAC 超清 MP4 视频** 与 **高清 PNG 截图**。

## 🌟 核心特性总览

### 1. 🖥️ 四大跨端视口模式 & 自由构图引擎
- **四端一键切换**：`💻 电脑网页端 (16:9)`、`📱 手机横屏影音 (16:9)`、`📲 手机竖屏社区 (9:16)`、`🔄 竖屏全屏观看 (16:9)`。
- **独立取景框（绿框）拖拽缩放**：支持在浮窗或舞台直接拖拽绿框及四角手柄自由裁切视频构图，内置 `12px` 边缘内缩出血算法，彻底消除源视频白边/黑边割裂感。
- **舞台无损放大镜 (`50% ~ 350%`) + 抓手平移 (`M` 键)**：支持滚轮无级缩放检查像素细节，导出截图与录屏时自动还原 100% 原始满画幅。
- **全画面点击即定位**：点击左侧预览画面的任意元素（状态栏、主播头像、福利胶囊、送礼横幅、公屏弹幕、Logo 水印等），右侧工作台自动切换分区、滚动置顶并高亮对应设置卡片。

### 2. 🔴 Laya 沉浸式直播间系统（两阶段进房 + 1:1 像素级光效导出）
- **两阶段真实交互**：支持「阶段一：外流推荐页动态音波呼吸头像（点击进房）」与「阶段二：完整沉浸式直播内页」自由切换。
- **真人感滚动公屏 + 29 款高清黄脸表情**：内置无黑边高清表情精灵库与 29 款常用社交黄脸表情，支持蓝钻财富等级（`Lv.1~60`）、星钻贵族、粉丝团原生 SVG 勋章，双击任意单行弹幕即可原地编辑。
- **顶部定制限时福利胶囊**：支持自定义文案、宽高尺寸调节、画布自由拖拽摆位，内置流光扫光、呼吸脉冲、霓虹闪烁等 **8 种炫彩动效**。
- **16 款热门礼物轮播状态机**：每次弹出自动轮换不同真人头像 + 昵称 + 礼物连击，独立控制 **停留时长 / 渐隐消失时长 / 下一波间隔时长**。
- **跨平台无黑边飘赞表情精灵**：内置纯本地 Base64 柔和发光表情精灵图，彻底解决不同电脑系统字体渲染不一致或黑边色块问题，DOM 预览与 Canvas 导出 100% 一致。
- **15 项直播间全元素显隐矩阵**：任意 UI 部件一键独立开启或隐藏，预览与导出实时同步。

### 3. 🤖 Gemini 视觉 AI 看片写弹幕（25~150 条长句自定义 + 多模型容灾）
- **多帧视觉理解**：自动抽取当前视频关键画面，调用云端 Gemini Flash 视觉多模态链路（内置三模型自动容灾回退），结合画面动作与氛围生成地道台湾/海外繁体长句互动弹幕（单条 `14~32` 字自然口语）。
- **自定义条数与分批并发**：默认一次生成 **25 条**，支持滑块或输入框自由指定 **1 ~ 150 条**（大批量自动分批请求组装，零截断），同时支持管理员专属无限制解锁开关与隐藏暗号模式。
- **直播间与飘屏弹幕工坊双端同步**：一键生成即可同时驱动直播间滚动公屏与横竖屏顶部飘屏弹幕轨道。

### 4. 📱 千人千面真机状态栏（每次打开全随机 + 14 款真实海外/社交 App 通知图标）
- **每次刷新绝不重样**：每次打开或刷新网页，手机顶部状态栏的 **时间、电量百分比、运营商（中华电信/远传/台哥大/CSL/Singtel 等）、5G/WiFi 网络制式、实时网速、系统小图标、Laya 状态栏标样式（默认紫标，支持多款一键切换）** 全部自动焕新组合，自动对比上次快照杜绝雷同；亦支持一键锁定当前状态栏。
- **14 款真实软件通知小图标 + 自定义上传**：内置 **X (Twitter)、Instagram、短信、WhatsApp、Telegram、LINE、Gmail、Messenger、YouTube、TikTok、Discord、Facebook、微信、未接来电** 单色矢量通知图标，默认智能随机搭配 `1~3` 个，支持手动点选增删、随机换一批或自行上传任意 PNG/SVG 图标，截图与 MP4 导出均保持高清纯白/深色自适应渲染。

### 5. 💬 海外华人社区评论抽屉（80%+ 男性真实昵称 + 全链路防重名）
- **真实海外华人用户画像**：评论区与公屏昵称由 AI 与本地双引擎驱动，重点覆盖北美、澳新、新马、港澳台等海外华人圈层，**男性用户昵称占比稳定 80%~85%+**。
- **跨批次去重与零跨域离线头像库**：每次生成均自动比对历史已用昵称黑名单确保绝不重名；内置 **340+ 张纯离线高清华人真人 Base64 头像库**（`196+` 女生 + `144+` 男生 + 萌宠/氛围图），彻底告别外链跨域报错与截图空白。
- **丰富互动编辑**：支持评论抽屉高度上下拖拽（`28%~78%`）、整体字号缩放、作者回复、二级网友跟评、评论配图及单项独立 🎲 随机筛子。

### 6. 🔊 原声常开播控系统 + 画面右侧智能伸缩音量条 + 空格键专属播控
- **原声默认常开守护**：上传视频或刷新恢复视频时**默认全程开启原声**，底层防误触静音守护确保除非用户主动点击时间轴右侧的静音按键，否则视频始终保持有声播放。
- **右侧「细线 → 悬浮展开」音量调节条**：紧贴视频画面右侧外缘，平时不碰仅为一条 **4px 极细指示条**（绝不遮挡画面、不进入导出成品）；鼠标碰触或按住时丝滑放大展开为胶囊滑轨，支持**上下拖动圆钮**或**滚动鼠标滚轮**无级调节 `0% ~ 100%` 音量（触屏亦可直接滑动）。
- **空格键 (`Space`) 全局专属播放/暂停**：在非文字输入状态下，按空格键严格且唯一控制视频的**播放与暂停**，自动清除聚焦按钮焦点，杜绝按空格误触其他功能按键。

### 7. 🎥 WebCodecs 超清防模糊 MP4 录屏导出（帧级时长锁定）
- **硬件级恒定高质量量化 (`QP = 14 / 16`) + 全关键帧防呼吸模糊**：升级 WebCodecs `avc1.640028` (High Profile) 硬件编码策略，优先启用恒定量化参数（`quantizer: 14~16`）与高密度关键帧，配合最高 `28 Mbps` 超高码率兜底，彻底根除运动画面局部瞬时马赛克与周期性模糊。
- **0.1 秒帧级时长锁定**：底部可视化音轨波形裁剪器与顶部时长控件双向精确到 `0.1 秒`（设定 `13.6s` 即严格输出 `408` 帧 `13.60s`），内置 `faststart` 头部置顶封装，导出即发各大社交平台。

## 🛠️ 快速开始与本地运行

本项目采用原生 HTML5 + CSS3 + ES2022 模块化架构，**无需编译构建**，开箱即用：

```bash
# 1. 克隆仓库到本地
git clone https://github.com/Sorenskr/laya-player-beta.git
cd laya-player-beta

# 2. 方式 A：直接双击 index.html 即可离线运行全部核心功能
# 3. 方式 B：启动任意静态本地服务（推荐，可获得最佳 WebCodecs 与音频体验）
npx serve . -p 8080
```

### 目录结构说明
| 文件 / 目录 | 功能职责说明 |
| :--- | :--- |
| `index.html` | 主工作台界面结构、四大真机视口壳层、右侧折叠式快速访问编辑栏与底部剪映级时间轴 |
| `style.css` | 四端真机响应式皮肤、日夜间主题、直播间动效、顶部福利胶囊 8 种特效与右侧智能双态音量条样式 |
| `player.js` | 视频/图片持久化引擎（IndexedDB）、原声常开守护、右侧伸缩音量条交互、空格键专属播控、取景框与波形时间轴 |
| `danmaku.js` | 多轨道防重叠飘屏弹幕渲染引擎、悬停暂停与单条可视化精修系统 |
| `app.js` | 沉浸式直播间合成器、Gemini 视觉 AI 多模型链路、千人千面状态栏引擎、海外华人评论抽屉与 WebCodecs MP4 超清导出管线 |
| `logos.js` | 双品牌高清无损矢量/位图资产与 340+ 张离线高清海外华人真人头像 Base64 图库 |
| `api/claim-identity.js` | Vercel Serverless 跨设备昵称/头像去重协同接口（静态托管与离线环境自动无缝降级） |
